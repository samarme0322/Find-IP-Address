# Find IP Address

This project is a simple Python script that uses the built-in `socket` module to display:

- your computer's hostname
- your local IP address
- the IP address of `github.com`

## Files

- `Find_IP_Address.py` - the main script that performs the DNS lookups and prints the results

## Requirements

- Python 3.x

## How to Run

From the project folder, run:

```bash
python3 Find_IP_Address.py
```

## Example Output

The script will print the hostname and IP details for the current machine and for `github.com`.
